# 🚀 NexTalk - Real-time Chat Application

NexTalk is a high-performance, real-time chat application. It uses a modern tech stack to ensure that messages are delivered instantly and stored securely.

## 🌟 Key Features
* **Instant Messaging**: Powered by WebSockets for zero-latency communication.
* **Persistent Storage**: All messages are saved in a database, so your history is never lost.
* **Full Message Control**: Users can edit or delete their own messages in real-time.
* **Automatic UI Updates**: The chat automatically scrolls to the latest message.
* **Session Management**: Remembers your username using local storage for a seamless experience.

## 🛠 Tech Stack
* **Frontend**: React (Vite), Tailwind CSS
* **Backend**: Node.js
* **Communication**: WebSockets (WS)
* **Hosting**: Render

## 🚀 How to Run Locally

1. **Clone and Setup**
   ```bash
   git clone [https://github.com/Sivalije58/NexTalk](https://github.com/Sivalije58/NexTalk)
   cd NexTalk
   npm install
   npm run dev ```
